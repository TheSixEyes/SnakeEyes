## Translation Notes

1. **Emojis Preserved:** All emojis are kept in both languages for visual consistency
2. **Proper Names:** "Taylor" and institution names remain unchanged
3. **Technical Terms:** Programming language names remain in English as per convention
4. **Platform Names:** OS names (Windows, MacOS, Linux) unchanged
5. **Formatting:** String formatters (%1$d, %2$d) preserved for dynamic content
6. **Punctuation:** Spanish punctuation rules applied (¡ ¿)
7. **Capitalization:** Maintained appropriate Spanish capitalization rules

## String Resource Keys

All strings use the same resource key in both languages:
- `R.string.game_title` → "PIG" (English) / "CERDO" (Spanish)
- `R.string.roll_button` → "ROLL" (English) / "TIRAR" (Spanish)
- etc.

This allows the app to automatically select the correct translation based on device locale.
